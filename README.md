# DSA

This repository contains a comprehensive collection of Data Structures and Algorithms (DSA) problems and their solutions in Java, sourced from various competitive programming platforms and educational resources. It is structured to facilitate learning and practice, from fundamental concepts to more advanced topics.

## 📂 Repository Structure

The repository is organized into the following main directories:

*   **`Strivers A2Z DSA Course/`**: Solutions for problems from the popular [Striver's A2Z DSA Course](https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z). This section is meticulously categorized by topic:
    *   `Things to Know`: Basic Java constructs (If/Else, Loops, Switch).
    *   `Patterns`: A collection of pattern-printing problems.
    *   `Know Basic Maths`: Fundamental mathematical algorithms (GCD, Prime, Palindrome).
    *   `Learn Basic Recursion`: Introductory recursion problems (Factorial, Fibonacci).
    *   `Learn Basic Hashing`: Hashing concepts for frequency counting.
    *   `Learn Important Sorting Techniques`: Implementations of various sorting algorithms like Bubble, Insertion, Selection, Merge, and Quick Sort.
    *   `Problems on Arrays`: Array-based problems categorized by difficulty (Easy, Medium, Hard).
    *   `Binary Search`: Problems on binary search, divided into searching on 1D arrays and on answers.

*   **`CodeChef/`**: A large collection of solutions for problems from CodeChef contests, organized by difficulty rating:
    *   `Rating 0 to 500`
    *   `Rating 500 to 800`
    *   `Rating 800 to 1000`
    *   `Rating 1000 to 1200`
    *   `Rating 1200 to 1400`

*   **`Geeks For Geeks/`**: Solutions for practice problems from Geeks for Geeks, categorized by data structure:
    *   `Arrays`: Problems like moving zeros, reversing, and finding the majority element.
    *   `Linked List`: A text file with a list of common Linked List questions.

*   **`Data Structures/`**: Contains text files with curated lists of practice questions for specific data structures, such as Linked Lists.

## ✨ Key Topics Covered

This repository covers a wide range of DSA topics, including but not limited to:

*   **Arrays**: Searching, Sorting, Rotation, Subarray problems.
*   **Sorting**: Bubble Sort, Insertion Sort, Selection Sort, Merge Sort, Quick Sort.
*   **Searching**: Linear Search, Binary Search.
*   **Recursion**: Basic recursive patterns, factorial, Fibonacci series.
*   **Hashing**: Frequency counting, finding unique elements.
*   **Mathematics**: GCD, Prime numbers, Armstrong numbers, Palindromes.
*   **Linked Lists**: Basic operations and standard problems.
*   **Pattern Printing**: Various logical and numerical patterns.
